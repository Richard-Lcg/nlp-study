## 1. BERT文本分类和实体识别的关系

- **文本分类**（意图识别）是**句子级别**的任务，目标是预测整个句子的类别（如“查天气”、“订机票”）。在BERT中，通常使用 `[CLS]` 位置的输出向量作为句子表示，经过分类层得到类别概率。

- **实体识别**（槽位填充）是**token级别**的任务，需要对输入序列中的每个token预测一个标签（如B-城市、I-日期）。在BERT中，使用所有token位置的输出向量，每个向量经过一个分类层得到该token的标签。

**两者关系**：它们共享底层的BERT编码器，因此可以联合学习通用的语言表示。意图和槽位往往存在内在关联（例如“查天气”意图常伴随“地点”槽位），联合训练可以互相促进，提升两个任务的准确性。

## 2. 分别使用的loss

代码中使用了两个交叉熵损失（`nn.CrossEntropyLoss`）：

- **意图分类损失（seq_loss）**：  
  输入是 `seq_output`（形状 `[batch_size, num_intents]`），标签 `seq_label_ids`（形状 `[batch_size]`），直接计算交叉熵。这衡量模型预测意图类别与真实意图的差距。

- **实体识别损失（token_loss）**：  
  输入是 `token_output`（形状 `[batch_size, seq_len, num_entities]`），标签 `token_label_ids`（形状 `[batch_size, seq_len]`）。但只对有效token（`attention_mask` 中为1的位置）计算损失，通过 `active_loss` 和 `active_logits` 过滤掉padding部分的贡献。这确保模型只关注实际文本部分的标签预测。

## 3. 多任务训练直接相加的坏处及处理方法

### 坏处

- **梯度主导问题**：如果两个任务的loss数量级相差较大（例如一个任务loss远大于另一个），梯度更新会被大loss的任务主导，导致另一个任务训练不足，收敛缓慢甚至不收敛。

- **收敛速度不一致**：不同任务的学习难度和收敛速度可能不同，简单相加可能导致模型偏向于先拟合容易的任务，而忽略困难任务。

- **任务冲突**：某些情况下，两个任务的梯度方向可能相反，直接相加会导致相互抵消，损害整体性能。

### 处理方法

#### ① 加权求和

给两个loss分配不同的权重，使得它们的贡献平衡。例如：

```python
seq_loss_weight = 0.5 # 意图分类权重
token_loss_weight = 0.5 # 实体识别权重
loss = seq_loss_weight * seq_loss + token_loss_weight * token_loss
```

权重可以基于经验设定（如根据验证集性能调整），或根据loss的初始尺度设定（例如先观察几个epoch的loss值，让权重使两者量级相近）。

#### ② 动态权重调整

- **基于任务不确定性的加权**（Kendall et al., 2018）：将多任务学习建模为同方差不确定性，通过可学习的参数自动调整各任务权重。

- **基于梯度幅度的归一化**（GradNorm）：在训练过程中根据梯度范数动态调整权重，使各任务梯度幅度相近。

#### ③ 任务特定学习率或优化器

为不同任务的输出层设置不同的学习率（例如分类层学习率稍高），但共享层仍使用统一学习率。这可以在一定程度上缓解不平衡。

#### ④ 梯度裁剪与平滑

如果发现某个任务梯度爆炸，可对该任务的梯度进行裁剪，或使用梯度累积策略。

#### ⑤ 数据采样与标签平滑

若不平衡源于数据量差异（例如意图类别很多但槽位标注稀疏），可以尝试对样本进行重采样，或对标签进行平滑，减轻过拟合。

#### ⑥ 交替训练

不是同时优化两个loss，而是交替优化每个任务的loss，类似于多任务学习的“轮流训练”，可以避免梯度冲突。
