## 提示词设计：信息解析智能对话系统（意图识别与槽位填充）

### 任务背景

你是一个智能对话系统的信息解析模块。用户输入一段自然语言，你需要识别出用户的**意图**（如查询天气、订票等）以及**槽位信息**（如地点、时间、数量等实体），并以结构化格式输出。

### 数据标签说明

- **意图标签**：从以下列表中选择最匹配的意图：`["查天气", "订酒店", "订机票", "查路线", "听音乐", "设闹钟", "问百科", "其他"]`（注：实际标签请替换为 `intents.txt` 内容）

- **槽位标签**：采用BIO标注，实体类型包括：`["地点", "日期", "时间", "人名", "歌曲名", "数量", "其他"]`（实际请替换为 `slots.txt` 内容）。输出时需提取实体及位置。

### 输出格式要求

以JSON格式返回，包含以下字段：

- `intent`：字符串，识别出的意图

- `slots`：列表，每个元素为一个字典，包含 `entity`（实体文本）、`type`（实体类型）、`start`（起始字符索引）、`end`（结束字符索引，不包含该位置）。如果无实体，返回空列表。

### 示例

**示例1**  
用户输入：`“明天北京天气怎么样”`  
输出：

```json
{
 "intent": "查天气",
 "slots": [
 {"entity": "明天", "type": "日期", "start": 0, "end": 2},
 {"entity": "北京", "type": "地点", "start": 2, "end": 4}
 ]
}
```



**示例2**  
用户输入：`“帮我订一张后天去上海的机票”`  
输出：

```json
{
 "intent": "订机票",
 "slots": [
 {"entity": "后天", "type": "日期", "start": 3, "end": 5},
 {"entity": "上海", "type": "地点", "start": 6, "end": 8}
 ]
}
```

### 现在请解析以下用户输入

用户输入：`“{{用户话语}}”`

**注意事项**：

- 严格按照JSON格式输出，不要添加额外解释。

- 实体位置索引基于字符级别，从0开始计数。

- 如果同一实体出现多次，分别列出。

- 如果无法确定意图，使用“其他”；无法识别的实体不输出。

（注：`{{用户话语}}` 会被实际用户输入替换）
